# CV header icons

- **Lucide** (ISC): `email.svg` (mail), `globe.svg`, `location.svg` (map-pin), `phone.svg` — [lucide.dev](https://lucide.dev/)
- **Simple Icons** (CC0-1.0): `linkedin.svg`, `github.svg` — [simpleicons.org](https://simpleicons.org/)

Companion `.pdf` files are rasterized from the SVGs for reliable inclusion with `pdflatex` / Tectonic without Inkscape or `--shell-escape`.
